## Description

This repository contains a collection of Jupyter Notebook exercises focused on fundamental Data Science concepts and practical data analysis with Python.
The project covers multiple stages of the data analysis workflow, including data manipulation, numerical computing, exploratory data analysis, visualization, and working with structured datasets.

## Technologies

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Data analysis and exploratory data analysis (EDA)
* Data visualization

## Functionality

### Data Manipulation and Analysis

The notebooks demonstrate practical techniques for working with datasets using Python and Pandas.
The exercises cover:
* loading and inspecting datasets;
* selecting and filtering data;
* handling missing values;
* transforming and cleaning data;
* working with different data types;
* calculating descriptive statistics;
* grouping and aggregating data.

### Numerical Computing

NumPy is used for working with numerical data and performing efficient array-based calculations.
The exercises demonstrate:
* creating and manipulating arrays;
* mathematical operations with numerical data;
* vectorized computations;
* working with array dimensions and transformations.

### Exploratory Data Analysis

The notebooks apply exploratory data analysis techniques to investigate datasets and identify patterns and relationships within the data.
This includes:
* statistical analysis;
* distribution analysis;
* comparison of variables;
* identification of trends and patterns;
* correlation analysis.

### Data Visualization

The project includes visual exploration of datasets using Matplotlib and Seaborn.
The notebooks demonstrate the creation of different types of visualizations, including:
* histograms;
* scatter plots;
* bar charts;
* box plots;
* correlation heatmaps;
* other statistical visualizations.

### Jupyter Notebook Practice

The repository contains multiple independent notebooks covering different Data Science exercises and topics, providing practical experience with the Python data analysis ecosystem.
